# Unit Converter

A Python application for converting common measurement units.

## Features
- Length conversion
- Weight conversion
- Temperature conversion
- Automated tests using pytest

## Installation
Install dependencies:

    python -m pip install -r requirements.txt

## Testing
Run the tests:

    python -m pytest -v
